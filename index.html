  1. Downloadable preview macOS · Apple Silicon

    RealForge Workbench#

    A local-first desktop workbench for AI-assisted coding. Review proposed file changes as a diff and choose whether to apply them.

    React · TypeScript · Tauri · Rust

    View downloads ↗
    How patch review works: RealForge Workbench
    Coding workflow
    Start with a local workspace, generate a proposed patch, and review the diff before applying or cancelling it. Previewing the patch does not edit the files.
    Engineering focus
    The React and TypeScript interface handles review; the native Tauri layer checks for approval before writing the proposed patch to the workspace.
    Example: decide whether to apply a patch
    Suppose you ask for duration formatter tests: 0 seconds should render as 0s, and 90 seconds as 1m 30s. Check both expected results in the diff. Apply the patch only if it adds the tests and leaves the formatter unchanged; cancel if it rewrites the formatter.
    macOS preview
    Look for the Apple Silicon DMG under Assets on GitHub. The Workbench uses an Imagicast account, and coding runs require a configured model provider. Local inference is supported; account and connected features use network services. The Workbench source is private.

  2. Prototype Compiler tooling · AI-assisted

    RealLang#

    An experimental language with a Python compiler, structured diagnostics, and a C backend, exploring how language design can support AI-generated code.

    Python · Type checking · C codegen · Diagnostics

    Source ↗ (opens in a new tab)
    Compiler design & research scope: RealLang
    Implementation
    A lexer, parser, type checker, and C emitter form the current compiler pipeline. Structured diagnostics are designed to support programmatic repair.
    Research question
    Can explicit language semantics and machine-readable errors improve AI code generation and repair? A study harness exists; improved LLM reliability is a research goal, not a reported result.
    Development
    An Imagicast Studios project developed with AI assistance. Public source and status notes document the implemented language subset.

    Avoiding unnecessary database reads

    What I found
    I traced repeated database reads to a periodic check in one backend workflow. It kept checking even when the data hadn’t changed.
    What I changed
    I moved that workflow to synchronize when its data changed, instead of checking on a timer.

    How room saves work: HeartHaven
    System
    Supabase Realtime handles presence and position broadcasts. Host-owned database rows hold the canonical room and garden layouts.
    Key decision
    The editor sends its expected room version when saving and handles a conflict response if that version is stale. Row-Level Security policies define access to persistent player data.
    Scope
    A browser-based multiplayer project built with Next.js, TypeScript, Supabase, and PostgreSQL. Architecture and database migrations are available in the public repository.
