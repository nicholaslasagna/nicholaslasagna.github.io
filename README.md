# Nicholas Lasagna · Portfolio

Personal portfolio at https://nicholaslasagna.com, hosted by GitHub Pages.
Plain HTML, CSS, and JavaScript; no package installation or build step.

## Preview

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Open http://127.0.0.1:8765. Before publishing, check desktop and narrow layouts,
light/dark themes, keyboard navigation, project disclosures, and all local links.

## Checks

```sh
python3 tests/check_site.py
node --check script.js
```

Keep degree dates and availability consistent across the page and metadata.
Preserve project permalinks. Clearly distinguish implemented features from research
goals, identify AI assistance where relevant, and avoid unverified metrics or
sole-authorship claims. The linked PDF résumé is maintained separately.

GitHub activity is an optional enhancement: the rest of the site remains usable
when JavaScript, external fonts, or the contribution service is unavailable.
